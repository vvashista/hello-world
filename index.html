Quick start with VLC

  1. Install VLC Media Player.
  2. Download a playlist above, or clone this repo.
  3. In VLC: Media → Open File and select the .m3u file.
  4. Open the playlist panel (View → Playlist or Ctrl+L) to browse channels.
  5. Use Up/Down or PgUp/PgDn to switch channels like live TV.

From the command line:

git clone <this-repo>
cd hello-world
./scripts/watch-news.sh hindi
./scripts/watch-news.sh english --channel 2
